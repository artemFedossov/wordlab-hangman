# Wordlab - Hangman

A modern Hangman game built with C, WebAssembly,
JavaScript and Python.

## Project Overview

Wordlab is a modern implementation of the classic
Hangman game, designed as a full-stack web application.

The project aims to combine a game engine written in C
with a responsive web interface and a backend API.

## Planned Technologies

- C
- WebAssembly (Emscripten)
- HTML, CSS and JavaScript
- Python (FastAPI)
- PostgreSQL
- Git and GitHub
